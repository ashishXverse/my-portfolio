# Aashish Raj — Portfolio

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
Upload the three files (`index.html`, `style.css`, `script.js`) to GitHub Pages, Netlify, Vercel, or Firebase Hosting.

- Add your resume PDF if desired.
- Update experience/certification details as needed.
